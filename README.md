## 🌊 What is BiyoLink?

**BiyoLink** is a water-provider discovery and connection platform built for Somaliland.

It helps people find water trucks and providers, view their locations and real prices per liter, and contact them directly. Water providers can create an account, share their service information, and make their trucks easier for customers to discover.

> **Real providers. Real locations. Real prices.**

BiyoLink is the updated name and identity of the project formerly known as **Haga**.

## ✨ Core Features

| Feature | Description |
| --- | --- |
| 🗺️ **Interactive Map** | Browse water providers on a live Leaflet-powered map. |
| 🚛 **Water Truck Listings** | Discover providers and their service details. |
| 💧 **Real Pricing** | View provider-submitted prices per liter. |
| 📍 **Provider Locations** | Providers can share their GPS location. |
| 📞 **Direct Contact** | Connect with water providers directly. |
| 👤 **Accounts** | Customers and water providers can create accounts. |
| 📱 **Mobile-First UI** | Designed to work cleanly across phones and desktops. |
| 🔐 **Supabase Integration** | Authentication and application data are connected to Supabase. |
| 🌍 **Community Network** | The platform becomes more useful as verified real-world providers join. |

### For people who need water

1. Open BiyoLink.
2. Explore available providers on the map.
3. Check provider details and price per liter.
4. Contact the provider directly.

### For water providers

1. Create a BiyoLink account.
2. Choose the water-provider account type.
3. Publish your real service details.
4. Share your location so customers can discover you.

## 🛠️ Technology

BiyoLink is intentionally lightweight and web-first.

- **HTML5** — application structure
- **CSS3** — responsive interface and visual design
- **JavaScript** — application logic and interactions
- **Leaflet.js** — interactive mapping
- **Supabase** — authentication and backend data
- **CARTO tiles** — map tiles
- **GitHub Pages** — static deployment

---

## 🚀 Run Locally

BiyoLink can be run as a static web application.

```bash
git clone https://github.com/Raazimtech/biyo-link.git
cd biyo-link
```

Then open `index.html` in a browser, or use any local static server.

For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## 🎯 Project Vision

Access to water should not depend on guessing who has supply, where a truck is, or what a provider charges.

BiyoLink aims to make water access **more visible, more connected, and easier to navigate** by creating a practical digital network between people who need water and the providers who deliver it.

The project starts simple: **find → understand → connect.**
