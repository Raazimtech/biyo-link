# HAGA 💧

**Smart Water Network for Somaliland**

HAGA helps people find reported water availability, compare prices, report problems, and understand early shortage risk.

## MVP
- Live interactive water map
- Available / low-supply / empty status
- Water source and tanker cards
- Price visibility
- Community reporting flow
- Early-warning dashboard concept
- Responsive mobile-first UI
- Distinctive HAGA brand mark
- **Made by Raazim Tech** footer branding

## Run
Open `index.html` in a browser, or serve the folder with any static server.

The demo uses Leaflet + CARTO tiles for the map and localStorage for submitted demo reports.
